## Morpholog

[Morpholog](https://github.com/jordan-dimov/morpholog) is what you, or your AI agents, use to build safe, reliable and auditable business software at speed. The system is built around an executable business model: you write the rules once, and Morpholog enforces them independently of whoever proposes a change, whether a person, an application or an AI agent. Only changes the rules allow are saved, and each is recorded with the rules it passed. Open source under Apache 2.0.

[Glasshouse](https://github.com/jordan-dimov/glasshouse) is an open ETRM core for European power, built on Morpholog: trades, curves, positions, P&L and audit, without the black box.
